# Startup Funding Analysis Dashboard

## About the Project
This project analyzes startup funding data from 2015 to 2020 using Python, Pandas, and Streamlit.

It provides insights into startup investments, funding trends, sectors, cities, and investors through interactive visualizations.

## Features
- Overall startup funding analysis
- Startup-wise investment details
- Similar startup analysis
- Sector-wise funding analysis
- City-wise funding comparison
- Year-wise funding trends
- Interactive charts and visualizations

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Installation

Clone the repository:

```bash
git clone https://github.com/ghurraniamarjeet-byte/startup-deskborad.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run startup.py
```
